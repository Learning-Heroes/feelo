`app/index.tsx` is the Discover route (the app's home screen); there is no other Discover route to reuse.

### Mock (`discoverMock.ts`)

```ts
export interface ClipPlatform { name: string; color: string }
export interface ClipCardData {
  title: string; type: string; genre: string; durationLabel: string;
  progress: number; platforms: ClipPlatform[]; description: string
}
```

Values exactly from the task table. `type: '🎬 Película'`, `progress: 0.3`, platforms Netflix `#e50914` and Prime `#00a8e1` (the only hex allowed outside `src/theme/`).

### Card

Centred on a Noche background. Zones top to bottom, each with its `testID`: `clip-area` · `clip-title` · `clip-tags` · `clip-platforms` · `clip-description`.

- **Clip area:** solid surface (theme token), 16:9, badge `CLIP` top-left, `▶ 1:42` bottom-right, fixed progress bar at `progress` width (Violeta Feelo).
- **Title:** Sora 800, `numberOfLines={2}`, `ellipsizeMode="tail"`.
- **Tags:** two chips (`type`, `genre`).
- **Platforms:** one chip per platform with a dot in the platform colour; row not rendered when `platforms` is empty.
- **Description:** Sora 400, Texto 2.
- Card: radius 26, solid surface (no glass), chips radius 99 and background `rgba(255,255,255,.08)` (Brand book §10).
- Static: a plain `View` with `accessible` + `accessibilityLabel={clip.title}`; no `Pressable`, no gesture handlers, no navigation.

### Tokens added to `src/theme/`

From Brand book v0.2: `noche #0A0A10`, `violeta #8B7CF6`, `texto1 #F2F1F7`, `texto2 rgba(242,241,247,.62)`, `texto3 rgba(242,241,247,.34)`, `chip rgba(255,255,255,.08)`, radii `card 26` / `pill 99`, Sora font families, and a spacing scale. Card and clip-area surface colours are not in the Brand book: I'll use a derived solid surface (`rgba(255,255,255,.07)`, the Niebla fill without blur) for the card and a darker violet-tinted solid for the clip area — **Toni to confirm**.

### Deviations to flag

- The `CLIP` badge is fixed UI text. There is no i18n in the repo yet and the task forbids new deps beyond the scaffold, so it lives as a constant in `ClipCard`; it moves to i18n when i18n lands. (Brand book also says "no sustained caps" — the task asks for `CLIP` explicitly, so I follow the task.)
