# Comandos de Claude Code

Comandos reutilizables para tareas frecuentes de este repo. Cada `.md` es un comando invocable con `/nombre-del-archivo`.

- `nueva-feature.md` — implementar una feature siguiendo el flujo del repo.

Pendientes de añadir cuando haga falta: revisar código, documentar cambios, preparar PR, generar tests (se pueden apoyar en las skills oficiales `code-review` y `commit` de Claude Code en vez de reescribirlas aquí).
