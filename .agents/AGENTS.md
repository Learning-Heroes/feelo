# .agents/AGENTS.md

Este archivo es un puntero para evitar duplicar reglas en dos sitios. La fuente de verdad para cualquier agente es la [`AGENTS.md`](../AGENTS.md) en la raíz del repo (es el archivo que las herramientas de IA buscan por convención).

El detalle vive aquí, en `.agents/`:

- [`rules.md`](rules.md) — convenciones del proyecto (idioma, estilo, estructura, validaciones, seguridad, documentación).
- [`workflows.md`](workflows.md) — flujos de trabajo esperados (crear tarea, implementar, probar, documentar, PR).
- [`skills.md`](skills.md) — índice de skills disponibles y cuándo usar cada una.
