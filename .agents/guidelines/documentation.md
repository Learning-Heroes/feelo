# Documentation

**Level**: blocking.

- If a change affects architecture, the data model or API contracts, update the corresponding doc (`docs/architecture.md`, `docs/database.md`, `docs/api-contracts.md`) in the same PR as the code.
- Decisions that can't be deduced from the code (why X over Y) go to `docs/decisions/` as an ADR, not as a code comment.
- What to document and at what level of detail: see the [`docs-and-testing`](../skills/docs-and-testing/SKILL.md) skill.
